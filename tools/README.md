# Инструменты подготовки набора данных

Три папки — три звена конвейера. Каждая работает с результатом предыдущей и больше
ни с чем, поэтому любую можно запускать и передавать отдельно. Состав набора готовит
`3dfront_dataset` до рендера, разметку — после него.

```
исходные GLB-комнаты  +  сырой 3D-FRONT (масштабы и классы)
        │
        ▼
3dfront_panorama_renderer     GLB → панорамы (RGB, глубина, нормали, экземпляры)
        │  outputs/<split>/<дом>/<комната>/{0..3}.hdf5 + render.json
        ▼
3dfront_dataset               панорамы → разметка в форматах, нужных сетям
        │  rgb/, ground_truth/, coco/, horizonnet/, dpc_dataset/
        ▼
3dfront_training              разметка → обученные веса
           training/detector/, training/horizonnet/
        │
        ▼
benchmark-toolbox (корень репозитория)   веса → предсказания → метрики → таблицы статьи
```

## Порядок выполнения

1. **Состав набора.** `prepare.py freeze` перебирает комнаты источника, отбраковывает
   непригодные с записью причины и делит остальные по домам. Запускается один раз на
   источник; готовое разбиение не перезаписывается без явного `--force`.
2. **Рендер.** [`3dfront_panorama_renderer`](3dfront_panorama_renderer/README.md) —
   единственная часть, которой нужен Blender. Не знает ни о разметке, ни об обучении:
   на входе папка комнаты, на выходе панорамы. Сначала запускается с `--plan-only`,
   чтобы отсеять комнаты, где камеру поставить негде, и только потом на полный рендер.
3. **Подготовка данных.** [`3dfront_dataset`](3dfront_dataset/README.md) — процессор,
   Blender не нужен. Восстанавливает метры, режет разметку по форматам: COCO для
   детектора, плотные цели для HorizonNet, трёхмерные рамки для оценки, ссылки для DPC.
   Здесь же проверки согласованности и фиксированное разбиение с перечнем исключений.
4. **Обучение.** [`3dfront_training`](3dfront_training/README.md) — нужен GPU и
   окружение Pano3D. Детектор и HorizonNet обучаются независимо друг от друга.
5. **Оценка.** Корень репозитория: `benchmark-toolbox run --config <конфиг>` прогоняет
   метод по единой методике оценивания и пишет предсказания, пометричные значения,
   сводку и отчёт.

Полная последовательность команд — в [README репозитория](../README.md).

## Что где не лежит

Данные, журналы запусков и отчёты просмотра не входят ни в одну из папок: они
остаются в игнорируемой Git папке `artifacts/` или в отдельном эксперименте на
вычислительной машине.
